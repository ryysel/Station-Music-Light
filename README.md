# Свет Яндекс Музыки

Скажи «Алиса, включи музыку» — кольцо (или логотип на первой Мини) окрасится в цвет обложки. Зоны делятся на три группы: бас, середина и верхние частоты. При смене обложки меняется цвет. На паузе плагин освобождает кольцо, а при обращении к Алисе уступает ей подсветку.

**Нужна только Luna 0.2.39 или новее.** AirPlay устанавливать не нужно. Выбирай файл `.yampkg` по своему профилю YAM (модель можно посмотреть в Luna).

| Станция | Профиль пакета | Где светится |
|---|---|---|
| Мини | `yandexmini` | Логотип |
| Мини 2 | `yandexmini_2` | Кольцо |
| Мини 3 | `bergamot` | Кольцо |
| Лайт | `yandexmicro` | Кольцо |
| Лайт 2 | `plum`, `yandexplum` | Кольцо |
| Миди | `cucumber`, `yandexmidi` | Кольцо |
| Стрит | `mango` | Кольцо |
| Станция 2 | `yandexstation_2` | Панель из 89 пикселей |

`0.1.0-rc.2` — пакеты для проверки. Цвет и пульсация подтверждены владельцем Мини 2 во встроенном пилоте. Для других моделей сборка архива ещё не означает, что подсветка проверена на живой станции. У Мини 3 Про и Станции 3 в сопоставленной версии Station-airplay нет этой индикации.

## Установка кандидата

1. Установи Luna и разреши запуск бинарных плагинов в её настройках.
2. Передай файл `music-light-0.1.0-rc.2-yandexmini_2.yampkg` на станцию. Из каталога с файлом выполни `yam install --yes ./music-light-0.1.0-rc.2-yandexmini_2.yampkg`.
3. В списке плагинов Luna включи **«Свет Яндекс Музыки»** и запусти сервис. Включи трек с обложкой. Чтобы отключить эффект, останови сервис в Luna.

Имя пакета в YAM — `airplay/music-light`: `airplay` здесь имя пространства пакетов. Единственная зависимость для станции — `yam/luna`. Если у тебя экспериментальный Station-airplay со встроенной подсветкой штатной музыки, верни обычный Station-airplay перед включением отдельного плагина, иначе оба будут менять одно кольцо.

## Откуда берутся свет и ритм

Плагин берёт адрес обложки из текущей музыкальной команды станции и загружает миниатюру по HTTPS с `avatars.yandex.net`. Частоты вычисляются на самой колонке из выходного стереобуфера ALSA. Микрофон не используется, аудио не сохраняется и не отправляется. Если миниатюру получить не удалось, кольцо остаётся штатной системе. Плагин читает параметры динамиков из конфигурации ALSA. При неизвестной конфигурации он не захватывает подсветку. На Станции 2 используется отдельный вывод в кадровый буфер: при паузе и обращении к Алисе плагин возвращает панель штатному аниматору.

## Сборка и проверка пакета

Нужны Linux, Go 1.23+, `yam-publish` и каталог `platforms` из [репозитория YAM](https://github.com/nyakokitsu/yam). `golang.org/x/sys` компилируется внутрь бинарника; устанавливать его на станцию не нужно.

```sh
go test ./...
YAM_PROFILES=/путь/к/yam/platforms ./package.sh
```

Скрипт собирает Linux ARM64 и ARMv7 (для Стрит), проверяет каждый профиль через `yam-publish check` и кладёт архивы и `SHA256SUMS` в `dist/0.1.0-rc.2/`. Установка пакетов и публикация в реестр при сборке не выполняются.
