# Свет Яндекс Музыки

Скажи «Алиса, включи музыку» — кольцо Станции Мини 2 окрасится в цвет обложки. Две зоны реагируют на бас, две — на середину, ещё две — на верхние частоты. При смене обложки меняется цвет. На паузе плагин освобождает кольцо, а при обращении к Алисе уступает ей подсветку.

**Поддерживается:** Яндекс Станция Мини 2 (`yandexmini_2`) с Luna 0.2.39 или новее. AirPlay устанавливать не нужно. Цвет и пульсация проверены на Мини 2 в составе пилота; отдельный пакет `0.1.0-rc.1` — кандидат для проверки перед публикацией в YAM.

## Установка кандидата

1. Установи Luna и разреши запуск бинарных плагинов в её настройках.
2. Передай файл `music-light-0.1.0-rc.1-yandexmini_2.yampkg` на станцию. Из каталога с файлом выполни `yam install --yes ./music-light-0.1.0-rc.1-yandexmini_2.yampkg`.
3. В списке плагинов Luna включи **«Свет Яндекс Музыки»** и запусти сервис. Включи трек с обложкой. Чтобы отключить эффект, останови сервис в Luna.

Имя пакета в YAM — `airplay/music-light`: `airplay` здесь имя пространства пакетов. Единственная зависимость для станции — `yam/luna`. Если у тебя экспериментальный Station-airplay со встроенной подсветкой штатной музыки, верни обычный Station-airplay перед включением отдельного плагина, иначе оба будут менять одно кольцо.

## Откуда берутся свет и ритм

Плагин берёт адрес обложки из текущей музыкальной команды станции и загружает миниатюру по HTTPS с `avatars.yandex.net`. Частоты вычисляются на самой колонке из выходного стереобуфера ALSA. Микрофон не используется, аудио не сохраняется и не отправляется. Если миниатюру получить не удалось, кольцо остаётся штатной системе. Разметка выходного буфера проверена только на Мини 2.

## Сборка и проверка пакета

Нужны Linux, Go 1.23+, `yam-publish` и каталог `platforms` из [репозитория YAM](https://github.com/nyakokitsu/yam). `golang.org/x/sys` компилируется внутрь бинарника; устанавливать его на станцию не нужно.

```sh
go test ./...
mkdir -p build dist
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -buildvcs=false -ldflags='-s -w' -o build/music-light .
yam-publish check --source . --profiles "$YAM_PROFILES"
yam-publish pack --source . --profiles "$YAM_PROFILES" --output dist/music-light-0.1.0-rc.1-yandexmini_2.yampkg
```

Код получения состояния штатного трека и анализ выходного микса перенесены из пилота Station-airplay. Плагин работает через API Luna; отдельного приёмника, веб-сервера или фонового менеджера устанавливать не нужно.

Для сопровождающего: после проверки самостоятельного пакета на станции готовый архив можно отправить на модерацию командой `yam-publish publish --source . --artifact dist/music-light-0.1.0-rc.1-yandexmini_2.yampkg --target yandexmini_2`. Нужна учётная запись владельца пространства `airplay`. Сборка и `pack` сами ничего не публикуют.
